# Bug跟踪列表

## Bug等级说明

| 等级 | 说明 | 示例 |
|------|------|------|
| P0 | 致命：系统无法使用或数据丢失 | 登录失败、数据丢失、安全漏洞 |
| P1 | 严重：核心功能无法使用 | 无法添加数据、页面报错 |
| P2 | 一般：功能异常但有替代方案 | 显示错误、样式错乱 |
| P3 | 轻微：体验问题，不影响功能 | 文案错误、UI细节 |

## Bug状态

| 状态 | 说明 |
|------|------|
| New | 新发现 |
| Confirmed | 已确认 |
| In Progress | 修复中 |
| Fixed | 已修复 |
| Verified | 已验证 |
| Reopened | 重新打开 |
| Won't Fix | 不修复 |
| Deferred | 延期处理 |
