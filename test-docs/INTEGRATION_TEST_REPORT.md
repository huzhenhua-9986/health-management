## 3. 问题清单

### Bug-001: 演示模式不验证密码

| 属性 | 值 |
|------|-----|
| **Bug ID** | BUG-001 |
| **标题** | 演示模式不验证密码 |
| **等级** | P2 (一般) |
| **状态** | Confirmed |
| **发现日期** | 2026-02-28 |
| **所属模块** | 用户认证 |

**描述**：
在演示模式下，登录接口不验证密码正确性，任意密码都能成功登录。

**复现步骤**：
1. 调用 POST /api/auth/login
2. 使用任意密码（包括错误密码）
3. 返回登录成功

**预期结果**：密码错误时应返回登录失败

**实际结果**：任意密码都返回成功

**影响范围**：演示模式特性，不影响生产环境配置真实数据库后的功能

**建议**：生产环境需要实现真实的密码验证逻辑
