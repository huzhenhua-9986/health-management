# 图片资源说明文档

## 概述

本文档列出了健康管理系统小程序所需的所有图片资源及其规格要求。

## 目录结构

```
health-miniprogram/
└── images/
    ├── logo.png                    # 应用Logo
    ├── default-avatar.png          # 默认头像
    ├── wechat.png                  # 微信图标
    ├── home.png                    # 首页图标（未选中）
    ├── home-active.png             # 首页图标（选中）
    ├── data.png                    # 数据图标（未选中）
    ├── data-active.png             # 数据图标（选中）
    ├── add.png                     # 录入图标（未选中）
    ├── add-active.png              # 录入图标（选中）
    ├── report.png                  # 报告图标（未选中）
    ├── report-active.png           # 报告图标（选中）
    ├── profile.png                 # 我的图标（未选中）
    ├── profile-active.png          # 我的图标（选中）
    └── empty.png                   # 空状态图
```

## 图片规格

### 1. 应用图标

| 文件名 | 尺寸 | 用途 | 格式 |
|--------|------|------|------|
| logo.png | 160×160rpx | 应用Logo展示 | PNG（透明背景） |

**设计建议：**
- 使用健康相关的图标设计
- 主色调使用 #667eea（紫色）
- 简洁、易识别

| 文件名 | 尺寸 | 用途 | 格式 |

## 临时解决方案

在正式图片资源准备好之前，可以使用以下方式：

1. **使用emoji代替图标**：代码中已大量使用emoji作为临时图标
2. **使用纯色占位图**：创建纯色PNG图片作为占位
3. **使用在线图标库**：从 iconfont、IconPark 等下载免费图标

## 图标资源推荐

以下是一些免费图标资源网站：

- [IconFont（阿里巴巴）](https://www.iconfont.cn/)
- [IconPark（字节跳动）](https://iconpark.oceanengine.com/)
- [Iconify](https://iconify.design/)
- [Flaticon](https://www.flaticon.com/)

## 注意事项

1. 所有图标应保持统一的视觉风格
2. 使用PNG格式以支持透明背景
3. 图标尺寸应为标准尺寸的2倍（@2x）以支持高清屏幕
4. 底部导航栏图标需要准备选中/未选中两种状态
5. 文件命名使用小写字母和下划线
